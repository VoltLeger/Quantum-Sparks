## 🎮 1. Концепция и Игровой Процесс

**Quantum Sparks** — это соревновательная тактическая карточная игра (Tactical CCG) в футуристическом научно-фантастическом сеттинге парящего мегаполиса Олимп, вдохновлённая механиками *Urban Rivals*, *Hearthstone* и *Mutants: Genetic Gladiators*.

### ⚡ Главные нововведения v1.1.0:
1. **Стартовая Колода ОДНОГО Клана:**
   - Новый игрок выбирает свой единственный стартовый клан (*Титаны*, *Астральные Стражи*, *Технократы*, *Теневики* или *Синдикат Хаоса*).
   - Вся стартовая коллекция формируется строго из карт выбранного клана.
   - Карты других кланов открываются по мере прохождения **Клановых Миссий**, открытия **Бустерпаков** и сделок на **Рынке**!
2. **База Данных Игроков и Авторизация:**
   - Полноценная локальная база профилей с возможностью редактирования всех полей (Кредиты, Кристаллы, ELO, Никнейм, Стартовый клан).
   - Регистрация с Gmail, логином, паролем и настраиваемым никнеймом (ник можно менять в любое время).
   - Экспорт и импорт базы данных в формате JSON.
3. **Легковесный Сетевой Режим Онлайн Дуэлей (PvP):**
   - Комнаты с 6-значными кодами (`QS-XXXX`) для дуэлей между игроками без платных выделенных серверов.
   - Быстрый автоподбор соперников со сходным рейтингом ELO.
   - Синхронное скрытое вскрытие карт и искр, расчет урона и динамический пересчет рейтинга ELO.
4. **Исправление GitHub Actions CI/CD:**
   - Устранена ошибка `Dependencies lock file is not found... cache: 'npm'`.
   - Обновлено на Node.js 22 LTS с флагом `--no-deprecation`.
   - Автоматическое извлечение версии из `package.json` и генерация `QuantumSparks-v1.1.0.apk`.

## ⚡ 2. Игровые Правила и Механика Искр

1. **Дуэль из 4 раундов:** В бой берутся ровно **4 боевые карты** (по одной на каждый раунд).
2. **Ресурс «Квантовые Искры»:** Стартовый запас — **12 искр**.
   - Каждая потраченная искра даёт:
     - **+1 к Силе** (Победа в раунде определяется наивысшей Силой)
     - **+2 к Урону** (Победитель наносит урон по HP проигравшего)
   - *Формула:*  
     `Итоговая_Сила = Базовая_Сила + Бонус_Клана + Умения + Искры`  
     `Итоговый_Урон = Базовый_Урон + Бонус_Клана + Умения + (Искры * 2)`
3. **5 Кланов и их бонусы:**
   - 🛡️ **Титаны:** Снижение входящего урона на -30% (мин. 3).
   - 🌌 **Астральные Стражи:** Фазовый пробой брони и вампиризм.
   - ⚙️ **Технократы:** Квантовая транспозиция и разгон искр (+3 урона за искру).
   - 🗡️ **Теневые Странники:** Снижение Силы врага на -8 единиц.
   - 💥 **Синдикат Хаоса:** +2 к Урону за каждую звезду карты (1–6★).

## ⚔️ 3. Боевой Интерфейс (Battle Arena)

Интерфейс боя воспроизводит эргономику мобильной киберспортивной тактической арены:
- **Альбомная ориентация (Landscape Mode):** Увеличенные портреты персонажей и четкие плашки умений и бонусов клана.
- **Сверху (Оппонент):** Аватар, никнейм, ранг ELO, HP (14) и Квантовые искры (12), 4 карты противника.
- **Снизу (Игрок):** 4 карты игрока с инжектором искр, расчет бонусов в реальном времени.
- **Центр столкновения:** Одновременный вылет карт, расчет 5 фаз боя, всплывающие цифры урона и анимации победы.

## 🚀 4. Автоматическая Сборка APK на GitHub (CI/CD)

В проект добавлен готовый пайплайн **GitHub Actions**: [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml).

### 📋 Команды в Git Bash для релиза v1.1.0:

```bash
# 1. Добавить изменения и сделать коммит
git add .
git commit -m "feat: release v1.1.0 - single-clan starters, player db, pvp multiplayer"

# 2. Отправить в ветку main (запустит GitHub Actions сборку APK)
git push origin main

# 3. Создать тег v1.1.0 для авто-создания релиза с APK
git tag v1.1.0
git push origin v1.1.0
```

### 📲 Где скачать готовый APK?
После пуша перейдите в ваш репозиторий GitHub во вкладку **Actions** (или **Releases**), откройте завершившийся запуск и скачайте файл `QuantumSparks-v1.1.0.apk` прямо на смартфон.
